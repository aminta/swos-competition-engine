# Examples

Specs that show the schema on real competitions. **Club names only**: no squads, no player data, no ratings.
Examples are JSON sources only (no compiled `.SWC` here: the reference binary is `tests/golden/sample.swc`).
Every example validates with both host profiles (`make test`).

| File | Content |
|---|---|
| `ita-serie-b.json` | Serie A + Serie B 2026-27: 40 clubs (press names), Serie A relegation, Serie B direct promotion + its play-off (3rd-8th) |
