# Spec schema swc/1 — frozen primitives list (2026-10-26, git tag `schema-v1`)

Source of the model: the OpenSWOS convergence docs (competition-engine-proposal §4, rule-catalogue §3), adapted to
the hosts' limits. This list is **frozen** for v1: a new primitive = a minor version (swc/1.x, old specs stay valid);
a changed meaning = swc/2 + a migration. Column "S0" = what `swcc` validates today; "engine" = the step that runs it.

## Codes (shared with format/swc_format.h; append-only)

- Tie-breakers: points, goal_difference, goals_for, goals_against, wins, away_wins, away_goals_for,
  head_to_head_{points,goal_difference,goals_for,away_goals}, fair_play, coefficient, previous_stage_rank,
  play_off_match, draw_lots, name, faithful_1996 (= the 1996 game: points, GD, GF, file order).
- Deciders (required on every knockout round, no default): aggregate, away_goals, extra_time, penalties,
  better_placed, replay, draw_lots, golden_goal.
- Home: draw, better_placed, better_placed_second_leg, neutral, fixed. Pairing: draw, seeded, bracket, fixed.

## Validator checks in S0

Schema types and unknown members (located), id syntax and uniqueness, club references, host file/ordinal limits
(`clubs_per_file`, no duplicates), participant counts, table rows (`table_rows` / `long_table_rows`), knockout
rounds add up to one winner, every round has a decider, outcome positions within the stage, `to` targets exist,
promoted/relegated need `to`, league sizes stay constant across levels, names in every language, host charset,
title / short widths, arena worst case within `arena_max`.
