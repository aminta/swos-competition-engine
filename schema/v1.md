# Spec schema swc/1 — frozen primitives list (2026-10-26, git tag `schema-v1`; current minor: swc/1.3)

Source of the model: the OpenSWOS convergence docs (competition-engine-proposal §4, rule-catalogue §3), adapted to
the hosts' limits. This list is **frozen** for v1: a new primitive = a minor version (swc/1.x, old specs stay valid);
a changed meaning = swc/2 + a migration. Column "S0" = what `swcc` validates today; "engine" = the step that runs it.

## Codes (shared with format/swc_format.h; append-only)

- Tie-breakers: points, goal_difference, goals_for, goals_against, wins, away_wins, away_goals_for,
  head_to_head_{points,goal_difference,goals_for,away_goals}, fair_play, coefficient, previous_stage_rank,
  play_off_match, draw_lots, name, faithful_1996 (= the 1996 game: points, GD, GF, file order),
  head_to_head_reapplied (v1.3).
- Deciders (required on every knockout round, no default): aggregate, away_goals, extra_time, penalties,
  better_placed, replay, draw_lots, golden_goal.
- Home: draw, better_placed, better_placed_second_leg, neutral, fixed. Pairing: draw, seeded, bracket, fixed, by_place (v1.3).

## Validator checks in S0

Schema types and unknown members (located), id syntax and uniqueness, club references, host file/ordinal limits
(`clubs_per_file`, no duplicates), participant counts, table rows (`table_rows` / `long_table_rows`), knockout
rounds add up to one winner, every round has a decider, outcome positions within the stage, `to` targets exist,
promoted/relegated need `to`, league sizes stay constant across levels, names in every language, host charset,
title / short widths, arena worst case within `arena_max`.

## v1.1 additions (2026-10-26, backward compatible; swcc validates them)

Added while writing a whole country (Italy 2026-27) in the schema; specs without them are unchanged.

| Addition | Where | Meaning |
|---|---|---|
| `sizes: [n, ...]` | `groups` / `round_robin` stage | groups of unequal size (sum = the stage's clubs; participants listed group by group); compiled into section `GRPS` |
| positions `LN` | outcomes, `entrants` | counted from the bottom (`L1` = last), so one rule fits groups of different sizes (`L2-L1`: the last two); encoded 128 + N |
| `per_group` (default true for `playoff`) | a `playoff` / `knockout` stage whose `entrants` come from a `groups` stage | one play-off per group; outcome counts multiply by the groups |

| `to: "out"` | outcomes | the club leaves the world (e.g. relegated below the lowest modelled level) |
| `refill: "pool"` | competition | the league is kept at its size from an off-world pool (the size check counts only its out-side) |
| `participants.source: [comp ids]` | competition with `from: "link"` | the competitions its entrants come from (moves are counted for the source league); compiled into section `SRCE`; *which places* enter is still prose (see the open list) |

## v1.2 additions (2026-11-02, backward compatible; swcc validates them)

What v1.2 adds, in short: parallel leagues filled by area (`to` list + `assign`), entrants as a list of places, and
the best clubs of one place across groups (`best_of`). Added while bridging every 4.0.5 pack (the SWOS 96/97 Mod's
`tools/swc_pack.py`). All three are optional: every v1.0 / v1.1 spec validates as before, with the same messages and
the same compiled bytes (the new section `TOLS` is written only when used; older readers skip it). A spec that uses
them says `"schema": "swc/1.2"`. `"swc/1"` and `"swc/1.1"` are the M1 schema (1.0 + 1.1): the additions are refused
there ("a 'to' list is swc/1.2: this spec says "swc/1""), so a reader knows from the header which constructs a spec
may hold.

| Addition | Where | Meaning |
|---|---|---|
| `to: [league ids]` + `assign: "geographic"` | outcomes | the clubs go to the **parallel leagues** of one level (Serie C's groups, El Salvador's zones), each club to the league of its `area` (the engine balances the sizes, S3). The list names 2 or more leagues of one `level`; `assign` is required with a list and only with a list. Compiled: the outcome's `target` = the first, every target in section `TOLS`, outcome flag bit 0 |
| `entrants: [item, ...]` | `playoff` / `knockout` / any stage with `entrants` | a list of places instead of one range: `["season#3", "season#6"]` (3rd v 6th). Items are `stage#N`, `stage#N-M`, `stage#LN`; a place may be listed once |
| `{"best_of": "stage#P", "count": K}` | an `entrants` item | the K best clubs placed P across the groups of a `groups` stage (the best runners-up), ranked by that stage's tie-breakers; `count` 1..groups. `per_group` cannot be used with it |
| a level of parallel leagues | size check | the leagues joined by a `to` list (and the league sources of one `from: "link"` competition, when they share a level) are counted as one level: the clubs that leave the level = those that come in (`refill: "pool"` on every one of them: at most). A linked competition with several sources of one level counts its moves once, for the level |

### Parallel leagues by area: the 4.0.5 rule and the `area` format

What `assign: "geographic"` means, as the SWOS 96/97 Mod 4.0.5 plays it (gplay.c `pg_season`, at the season end,
before the new season's tables are built). The engine (S3) implements this rule.

1. Every move is one **level** up or down the chain: into a single league as it is, into a level of parallel leagues
   by the club's `area` for that level. Clubs that stay are counted in their own league first.
2. The clubs coming into a level of parallel leagues are placed one by one (the clubs' order): the 1st choice if it
   has room, else room is made there (rule 3); then the same with the 2nd choice; else the league nearest to the 1st
   choice with room (by position in the `to` list; at equal distance the later one). Each league keeps its size.
3. Making room in a full league L moves one club already in L, the first found in this order: a club whose 2nd choice
   is `*` (to the league nearest to L with room); a club outside its 1st choice (back to it, when it has room); a club
   outside both its choices (to its 2nd); a club in its 1st choice (to its 2nd); a club with two choices and no ban (to
   the league nearest to L with room). A banned club (`!`) is only ever moved to one of its own choices.
4. A club with no `area` has, as its 1st choice at every level of parallel leagues, the position of its own league
   among its level's (from its division in the team file), and no 2nd choice; a club whose own league is a single
   league has no choice, and goes to the league nearest to the middle one with room.
5. No club leaves the lowest modelled level through this rule (`refill: "pool"` handles the bottom).

`area` (a club member, a string): one part per level of parallel leagues, top-down, joined by `/`; a single part
applies to every level. A part is:
- `X`: the X-th league of the level's `to` list (`A` = the first, up to `I`);
- `X,Y`: 1st choice X, 2nd choice Y (2nd choices `A`..`G`);
- `X,Y!`: as `X,Y`, and never any other league (a northern club never in the southern group);
- `X,*`: 1st choice X, else any league (second teams, the U23 sides);
- `reserve` (the whole value): a club of the off-world pool, placed when it comes in.

Examples (Italy 2026-27, Serie C in three groups A / B / C, Serie D in nine groups A..I): `"A,B!/B"` (Serie C: A, else
B, never C; Serie D: B), `"C,B!/H"`, `"A,*"`. `ok/v12_area.json` is a valid spec with every form. swcc keeps the text as it is; the engine (S3) reads it.

## v1.3 additions (2026-11-09, backward compatible; swcc validates them)

What v1.3 adds: the fields of the competition editor's part B (internal names agreed 2026-11-08). The same rule as
v1.2: every addition is optional, older specs validate and compile to the same bytes (new sections only when used),
and a spec using one says `"schema": "swc/1.3"`; under `"swc/1.2"` and older they are refused ("'parent' is swc/1.3:
this spec says "swc/1.2"").

| Addition | Where | Meaning |
|---|---|---|
| `parent: club id` | club | the club is a **second team** (Spain's B teams, Italy's U23 sides) of a first team of its own country. A parent is never a second team itself. Compiled into section `PRNT` (club, parent) |
| `second_teams: {highest: level}` | world `countries.<code>` | the highest level (1..32) a second team of that country plays. Compiled into section `SECT` (country, level) |
| (rule) | leagues | a second team never in its parent's league, never in a league above its country's `highest` |
| `joins: [item]` | a `knockout` / `playoff` round | clubs that enter at that round. An item is `club:<id>` (a named club); `<stage>#N-M` (places N..M of an EARLIER stage of the same competition, this season; `LN` from the bottom); `<competition>#N-M` (places N..M of another competition: its final table of this season if it ends before this round, else last season's); `{"from": <competition>, "clubs": n}` (n clubs of that competition by the quota rule). A `#` ref names a stage of this competition first; an id that is both a stage here and a competition is refused ("'x' is both a stage and a competition: rename one"); a stage never feeds itself, a competition never itself. Round counts: in a stage with `entrants` the joining clubs come on top; in a stage filled from `participants`, they are part of `count` (the first round takes `count` minus every club that joins later). Validated; compiled with the engine step that plays them (as v1.2's entrants lists) |
| `participants.quota: [{from, clubs, byes}]` | a cup's `participants` (instead of `clubs` / `from: "link"`) | `clubs` clubs from each competition; they add up to `count`; `byes` (default 0, at most `clubs`) of them skip the first round, and the quotas' byes are the first round's `byes`. Byes skip round 1 only: a club that enters later (Serie A's clubs at Coppa Italia's last 16) is a `joins` item of that round, not a bye |
| `pairing: "by_place"` | a round (code 4, appended) | the best placed v the worst placed of the round's clubs, by their places (3rd v 6th, 4th v 5th); editor presets write `entrants` + `joins` + `by_place`, there is no preset member |
| `skip_if: {points_gap_ge: n}` | a `playoff` stage | the play-off is not played when the gap in points between the places it decides is n (1..99) or more (Serie C / Serie D rule); only on a `playoff` stage |
| `pools: [{id, file}]` | world | the **pools** below the modelled levels, each in its own file (path relative to the spec). A pool file: `schema` ("swc/1.3"), `id` (= the world's), `country`, `divisions: [{id, names {lang}, size}]`, `clubs: [{id, name, division, strength, area, rank, host}]` (`strength` 0.00..2.50 in hundredths; `area`, `rank`, `host` {file, ordinal} optional; each division holds exactly `size` clubs), `up: {champion: n, playoff: <a playoff stage>}` (what leaves a division upwards), `feeds: [competition ids]` (leagues with `refill: "pool"` it refills). Club ids are unique across the world and all its pool files (a club in two pools would be swapped in twice). swcc reads the files through its loader, `swcc_set_loader` (the CLI: next to the spec; the editor: over the files it holds); without one, a located warning ("pool file "x" not checked: no loader") and only the world's list is checked. What `strength` means at relegation is the engine's mapping (may change); the member stays |
| `pool: id` | a competition with `refill: "pool"` | which of the world's pools refills it |
| `realloc: "by_rank"` | every league of a level (same country and `level`) | the summer re-allocation of the whole level by the clubs' `rank`; every league of the level says the same (the engine re-places a whole level) |
| `rank: 0..254` | club (world or pool) | the club's rank for `realloc`; absent = none |
| `chain: true` | every league of a level | the level is a link of the promotion chain; every league of the level says the same |
| `squad: 16 \| 20` | world | players per club in the host world: one size for the world, not per country. Validated; the host reads it with its world (4.2: 16) |
| `head_to_head_reapplied` | a tie-breaker code | UEFA's: head-to-head points, goal difference, goals for among the tied clubs; a smaller subset still tied takes the three again over its own matches only, until nothing splits. The other `head_to_head_*` codes go once, in list order, inside the blocks still tied (the default) |
